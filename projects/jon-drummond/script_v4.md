# Jon Drummond voiceover script v4: consistent, natural, pronunciation fixes

User feedback on v3 (5 Nov 2026): sounds robotic, especially toward the end. Some words mispronounced (Drummond came out as "Drumming", gold as "goal", Wilt as "Will", e'ry sprinter as "Earl sprinter", hisself as "herself"). Wants it consistent from start to finish.

Changes from v3:
- No IPA spellings. Plain gold, track, captain. The IPA is what made "gold" come out as "goal".
- "Drummond" spelled "Drummund" so it isn't read as "Drumming". e'ry becomes every, hisself becomes his self.
- Same voice_settings for every section: stability 0.45, similarity 0.85. v3 used 0.75, which gives a steady but flat, robotic read.
- No heavy time-stretching afterwards. Phrases are placed on the edit's timeline with tools/rephrase_voiceover.py (mild 0.95 atempo at most).
- Credits: about 9,700 characters, so roughly 9,500 credits per full take and about 20,000 for two takes per section.
